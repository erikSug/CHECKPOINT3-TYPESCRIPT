# Catálogo de Músicas

App em React Native (Expo) com login, cadastro, 100 mil músicas e tela de detalhe.
Checkpoint 3 · Mobile Development & IoT · FIAP

## Como rodar

1. `npm install`
2. `npx expo start`
3. Abra no Expo Go (QR code ou tecla `a` no Android)

## Telas

Login, Cadastro, Home, Lista (FlatList com 100 mil músicas) e Detalhe.
